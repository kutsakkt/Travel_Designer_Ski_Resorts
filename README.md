# Travel_Designer_Ski_Resorts
Проект выполнен для Travel Designer. 
Цель: подготовить рейтинг горнолыжных курортов в двух разных сценариях.
Задачи: подготовить код для сбора и обработки данных, а также для подсчёта весов курорта.

Что использовалось в работе:
1. Данные собирались с помощью скрипта collect_resort_open_data.py. Так были собраны данные по погодным условиям, трассам, инфраструктуре
2. Данные о стоимости ски-пассов, данные о туристических поездках и ночевках использовались из ранее сделанных выгрузках
   2.1. `prices_monthly.json` — цены по месяцам; первая строка содержит названия полей.
   2.2. `rosstat_tourist_trips.csv` — выгрузка туристских поездок по регионам.
   2.3. `rosstat_tourist_nights.csv` — выгрузка ночёвок по регионам.

**Алгоритм работы:**
1. Настройка окружения и запуск скрипта для парсинга collect_resort_open_data.py. Данная часть не отображена в приложенном скрипте, в нём код для анализа и подготовки рейтинга.
2. Объединение данных. Так как данные, собранные в Шаге 1, уже содержат информацию о климате и инфраструктуре, файлы climate_monthly и resorts не использовались.
3. Проверка на дубликаты и агрегация данных (подсчёт среднего по ночевкам и поездкам).
4. Заполнение пропущенных данных и исправление некорректно собранных данных:
   4.1. В столбец piste_segments_6km были перезаписаны данные о километраже, а не о сегментах. Это способствует более объективной оценке
5. Добавление данных о наличии сноупарка на курорте и возможности фрирайда. Данные были собраны вручную и с ИИ.
6. Добавление данных о количестве трасс по сложности. Данные были собраны вручную и с ИИ.
7. Расчёт статистик и подготовка оценок по критериям.
8. Расчёт рейтинга по двум сценариям.
9. Подготовка дашборда.


**Сценарии:**

*Спокойный отдых*
   В этом случае отдыхающему важна комфортная погода, умеренные осадки, транспортная доступность, несложные трассы.
Приоритет основных потребностей туриста.
1) Погодные условия — 27%.
2) Простые трассы и общая трассовая инфраструктура — 28%.
3) Подъёмники — 7%. Это отражает основную цель поездки: комфортно добраться до курорта и кататься в подходящих условиях.
Второстепенные факторы комфорта.
1) Проживание и питание — 15%.
2) Транспортная доступность — 13%.
3) Достопримечательности — 7%.
4) Стоимость ски-пасса — 3%.

*Активный отдых*
   В этом случае отдыхающему важно много снега, интересные трассы, возможность фрирайда и наличие сноупарка.
Основные направления для оценки:
1) Снежные условия. Свежий снег и продолжительный снежный сезон особенно важны для активного катания и фрирайда - 25%
2) Трассы и подъемники. Разнообразие трасс, наличие сложных спусков, масштаб территории катания и инфраструктура подъёмников - 41%
3) Фрирайд и сноупарк. Возможность кататься вне подготовленных трасс и заниматься фристайлом - 18%
4) Остальные факторы. Погода, проживание, питание, транспорт, стоимость и дополнительные развлечения - 16%

**Итоговые файлы:**

2) relax_raiting_df.csv - рейтинг курортов по спокойному сценарию
